# Clad marketing site

Astro static site for Clad (field software for telecom, utility, and infrastructure contractors).
Not a Propel project.

## Conventions
- Design source of truth is the Figma file (Clad design system). Read it through the Figma MCP; do not invent colors, type, or spacing.
- Tokens live in `src/styles/tokens.css` as CSS custom properties, generated from Figma variables. Components use tokens, never raw values.
- One Astro component per page section, in `src/components/`, composed in `src/pages/index.astro` top to bottom. Current order: Header, Hero, LogoBand, CtaBanner, ProductStory, Testimonial, Audiences (use cases + case studies, tabbed by audience), Changelog (dark band), Faq, Footer. Additional Tools was cut on 2026-09-25; the project board mock is no longer in the story.
- Copy marked DRAFT in component comments (Asset Owner features) is Claude's placeholder pending Jason/Jocelyn. Story headlines/subheads/features are Jason's and Jocelyn's; the Locates scene data is Claude's.
- Scroll animations are vanilla JS in `src/scripts/`, scroll-scrubbed (progress 0..1 per pinned section) using the actor/keyframe pattern from `reference/prototypes/build_e.py`. Respect `prefers-reduced-motion`.
- `ProductStory.astro`, `src/scripts/story.js` (engine) and `src/scripts/story.config.js` (keyframes) are GENERATED by `reference/gen_story.py` (run `python3 reference/gen_story.py` from anywhere); styles come from `reference/story.css`. Edit those, not the outputs. Layout (2026-10-09): each scene pins a two-column frame centered under the nav; left has label, headline, subhead and three stacked features (30% opacity, the current step at 100%, clickable to jump), right has the stage. Scroll progress splits into three steps at 0 / .36 / .69, and each step animates one thing. Scenes, in order: Billing (three daily updates roll in -> invoice built from them -> QuickBooks sync chip), Project Management (blank B&W blueprint -> redline draws and labels cascade -> weekly report draws -> dashed forecast), Locates (AI-drafted ticket types itself and submits -> your tickets clear/renew -> subcontractor tickets roll in). Every UI shows three line items and is coded HTML/SVG; there are no images in the story. Actors are positioned by center (x, y in % of the stage), width w, scale s. Copy follows Jason's Q3 homepage doc; the blueprint is traced from Jocelyn's start/end frames in `reference/figma/blueprint-*.png` (basemap cleaned by `blueprint-clean.py`, vectorized with potrace into `blueprint-map.svg`). Original Clad screenshots are in `reference/figma/story-screenshots/` for reference only.
- Hero has no load animation (tried and removed 2026-09-23); motion budget goes to the product story.
- Node is installed via Homebrew at `/opt/homebrew/bin`; run `npm run dev` for the dev server on port 4321.
