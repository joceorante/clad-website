# Clad marketing site

Astro static site for Clad (field software for telecom, utility, and infrastructure contractors).
Not a Propel project.

## Conventions
- Design source of truth is the Figma file (Clad design system). Read it through the Figma MCP; do not invent colors, type, or spacing.
- Tokens live in `src/styles/tokens.css` as CSS custom properties, generated from Figma variables. Components use tokens, never raw values.
- One Astro component per Figma page section, in `src/components/`, composed in `src/pages/index.astro` top to bottom.
- Scroll animations are vanilla JS in `src/scripts/`, scroll-scrubbed (progress 0..1 per pinned section) using the actor/keyframe pattern from `reference/prototypes/build_e.py`. Respect `prefers-reduced-motion`.
- `ProductStory.astro`, `src/scripts/story.js` (engine) and `src/scripts/story.config.js` (keyframes) are GENERATED by `reference/gen_story.py`, which must be run from `reference/prototypes/` (it imports the prototype build scripts). Edit the generator, not the outputs.
- Hero has no load animation (tried and removed 2026-09-23); motion budget goes to the product story.
- Node is installed via Homebrew at `/opt/homebrew/bin`; run `npm run dev` for the dev server on port 4321.

## Reference
`reference/prototypes/` holds the exploratory HTML prototypes and their Python build scripts. They are not part of the build.
